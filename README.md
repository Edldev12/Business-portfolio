# Modern Responsive Dashboard

A modern and responsive dashboard UI built with HTML and CSS.  
This project focuses on creating a clean dashboard layout with statistics, navigation, user information, customer feedback, referrals, performance information, and responsive design for desktop, tablet, and mobile devices.

## 📌 Project Overview

This dashboard provides a simple and modern interface for displaying business and customer information.

The design includes a sidebar navigation on larger screens and an icon-based navigation bar on smaller screens. The layout automatically adjusts depending on the screen size.

The project was built as part of my frontend development practice to improve my skills in:

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design
- Media Queries
- Modern UI Design

## 📱 Responsive Design

The dashboard is designed to work across different screen sizes.

### Desktop

- Sidebar navigation
- Multi-column statistics
- Multiple dashboard cards
- Large content areas

### Tablet

- Reduced sidebar width
- Two-column statistics
- Adjusted dashboard cards

### Mobile

- Sidebar changes to an icon navigation bar
- Statistics stack vertically
- Dashboard cards stack vertically
- Customer cards use a two-column layout
- Images resize automatically
- Content fits smaller screens
